Flyer ➔ ICS Calendar

An offline-first, privacy-focused Progressive Web App (PWA) that converts image flyers into standard .ics calendar events using client-side AI image parsing.

🌟 Features

Privacy First: All calculations and image uploads occur client-side. Your API key is stored only in your browser (localStorage).

PWA & Mobile Ready: Add to home screen on GrapheneOS, Android, iOS, or desktop browsers.

Smart Event Parsing: Automatically extracts event title, start/end dates, times, venue locations, and detailed notes from image uploads or photos.

Export Formats:

Download .ics files for native calendar apps.

Copy raw .ics plaintext for web calendars (e.g., Proton Calendar).

Copy clean text summaries.

🔑 Getting a Free API Key

Go to Google AI Studio.

Click Get API key in the sidebar.

Click Create API key in new project and copy your key.

🚀 Quick Start

Host index.html using GitHub Pages or open it locally in any browser.

Click the Settings gear icon in the app header and paste your API Key.

Upload or snap a photo of any flyer to extract calendar event details!
